## Highlights

We are thrilled to announce the official **v1.0.0 General Availability** release of **MJDM (MJ Download Manager)**!

MJDM is an IDM-class download accelerator designed for Windows 10/11 and modern Linux desktop environments. It delivers up to **500% faster download speeds** by dynamically segmenting files into up to **32 parallel TCP connections**, while maintaining a clean, bloat-free user interface with zero telemetry and zero adware.

## System Requirements

- **Windows:** Windows 10 (1809+) or Windows 11 (64-bit). Microsoft Edge WebView2 runtime (included in Windows 11 and recent Windows 10 updates).
- **Linux:** Any modern distribution with `glibc 2.31+`, `gtk3`, and `webkit2gtk-4.1`. Supports GNOME, KDE Plasma, XFCE, Cinnamon under both X11 and Wayland.
- **Hardware:** Minimum 512 MB RAM (typical engine memory usage is < 45 MB).
